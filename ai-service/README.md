# Интеллектуальный сервис DocFlow

Python / FastAPI / PyMuPDF / scikit-learn. Существующая модель TF-IDF + LogisticRegression не изменена.

## OCR

Документы загружаются только в PDF. Встроенный текст извлекается напрямую. Страницы без текста с изображениями или векторными рисунками, а также страницы с растровым изображением размером от 20% страницы распознаются локальным Tesseract, встроенным в PyMuPDF. Поддерживаются русский и английский. Распознавание всего изображения страницы учитывает её PDF-поворот.

Языковые данные `rus.traineddata` и `eng.traineddata` должны находиться в `ai-service/models/tessdata`. Альтернативный каталог задаётся переменной `TESSDATA_PREFIX`. Отдельная установка tesseract.exe и новые Python-библиотеки не требуются.

Источник моделей: [официальный tessdata_fast 4.1.0](https://github.com/tesseract-ocr/tessdata_fast/tree/4.1.0), лицензия Apache-2.0. Модели должны быть установлены до запуска; во время обработки файлов ничего не скачивается. Для другого компьютера установите их командой из каталога `ai-service`:

```powershell
.\.venv\Scripts\python.exe scripts\setup_ocr.py
```

Ограничения: максимум 20 страниц OCR на документ; до 12 млн пикселей при рендеринге страницы; 250 DPI, уменьшаемые для крупных страниц; 20 секунд на один OCR-процесс, 45 секунд на OCR всего документа. Процесс завершается по таймауту. При ошибке сохраняется встроенный текст. Неполное распознавание запрещает автоматическое принятие типа документа.

Встроенный текст сохраняется и при успешном OCR; распознанные строки дополняют его с удалением точных повторов. Обработка PDF выполняется последовательно на отдельном потоке, чтобы не блокировать FastAPI и не запускать PyMuPDF одновременно в нескольких потоках. При одновременном запросе второго PDF API возвращает 503 с предложением повторить запрос; проверки здоровья продолжают работать.

`ocrUsed` означает, что OCR был выполнен. `requiresOcr` означает, что остались нераспознанные страницы либо полезного текста нет. При `requiresOcr=true` документ остаётся на ручной проверке. Эти поля могут одновременно быть true. Прежние поля API сохранены; backend сохраняет `ocrUsed` в существующем поле `ocr_used`, миграция БД не нужна.

Изображения низкого качества и рукописный текст могут распознаваться с ошибками. Уверенность классификатора — оценка типа документа, а не точности OCR.

## Запуск и проверка

Из каталога `ai-service`:

```powershell
.\.venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8000
.\.venv\Scripts\python.exe -B -m unittest discover -s tests -v
```

OCR-тесты создают настоящие PDF-сканы из изображения русского договора и проверяют распознавание, смешанные страницы и классификацию. Для генерации тестовых PDF нужен системный шрифт Arial (Windows) либо DejaVu Sans (Linux).

Готовый пример: `examples/ocr-scan-contract.pdf` — PDF без встроенного текста. `examples/ocr-result.json` — результат его фактического распознавания и классификации. Договор вымышленный, персональных данных нет.
