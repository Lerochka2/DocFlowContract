# OCR для PDF — план и решения

Цель: распознавать русские и английские сканы внутри PDF, сохраняя существующие API, модель классификации, роли и обработку документов.

Решение: PyMuPDF и его встроенный Tesseract. Языковые модели хранятся локально; документы не отправляются во внешние сервисы. Каждый OCR запускается в отдельном процессе с таймаутом. Обычный текст читается прежним способом. Для смешанного документа обрабатывается каждая страница; страницы с крупными растровыми изображениями распознаются целиком.

Ограничения: не более 20 OCR-страниц, 12 млн пикселей на страницу, 20 секунд на страницу и 45 секунд OCR на документ. При недоступных моделях, ошибке или неполном OCR сохраняется доступный текст, требуется ручная проверка; автоматическое принятие классификации запрещено. Формат загрузки остаётся только PDF.

Проверка: настоящий PDF только с изображением русскоязычного договора; обычный текстовый PDF; смешанный PDF; страница с текстовым колонтитулом и сканом; пустая страница; отсутствующие языковые модели; таймаут и лимиты; повреждённый PDF; совместимость API и сохранение ocrUsed в backend.

Независимая проверка выявила потерю точных встроенных полей после OCR, неверное сравнение координат повёрнутой страницы и блокировку event loop. Все три случая воспроизведены падающими тестами и исправлены: встроенные строки сохраняются, координаты приводятся через rotation_matrix, обработка PDF вынесена в один выделенный поток с быстрым отказом при занятости. Дополнительно проверяется освобождение слота после отмены запроса.

TF-IDF и текущая обученная модель в эту доработку не входят.
